# Base.vn 2.0 - Hệ điều hành Doanh nghiệp trong kỷ nguyên AI

Trang web giới thiệu nền tảng Base.vn 2.0 Agentic OS và Bảng giá dịch vụ.

## Cấu trúc thư mục

- `index.html` - Trang chủ Base.vn 2.0 (Hero Section, Kiến trúc Agent đa tầng, Testimonial auto-play carousel, Giải thưởng, CTA và Footer)
- `bang-gia/index.html` & `bang-gia.html` - Trang Bảng giá dịch vụ (Thanh trượt tính giá theo nhân sự thời gian thực, 5 gói cốt lõi Starter/Growth/Business/Enterprise/Agentic OS, Bảng so sánh tính năng chi tiết, Gói Combo, Bảng giá mua lẻ, AI Credit và FAQ)
- `Home/` - Thư mục gốc thiết kế đồng bộ
- `assets/` - Toàn bộ tài nguyên hình ảnh (Ảnh chân dung CEO Testimonial, Huy hiệu giải thưởng, Logo)

## Chạy thử nghiệm cục bộ

Khởi chạy web server đơn giản với Python:

```bash
python -m http.server 3000
```

Truy cập:
- Trang chủ: [http://localhost:3000](http://localhost:3000)
- Bảng giá: [http://localhost:3000/bang-gia](http://localhost:3000/bang-gia)
